# Спиральная матрица

Асинхронная библиотека: скачивает квадратную матрицу (NxN) с удалённого сервера и возвращает обход по спирали против часовой стрелки.

Исходное тестовое задание (Авито): https://github.com/avito-tech/python-trainee-assignment

## Что сделано
- get_matrix(url) — сигнатура ровно как в задании.
- Парсер формата +---+ / | 1 | с проверкой: пусто, не числа, рваные строки, неквадратная матрица.
- Обход против часовой стрелки для любого N.
- Ошибки сервера и сети -> MatrixError с понятным текстом.

## Что не сделано
Кэш, PyPI, неквадратные матрицы, так как не требуется по заданию.

## Как запустить
```bash
pip install -r requirements.txt
pytest               # быстрые тесты, без сети
pytest -m network    # только test_get_matrix из задания, на настоящем URL
```

## Как проверял
pytest -m network возвращает требуемый результат из задания - [10, 50, 90, 130, 140, 150, 160, 120, 80, 40, 30, 20, 60, 100, 110, 70].
